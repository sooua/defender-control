# Landing page

Static marketing page for **Defender Control**, built with the Vercel / Geist design system. No build step — plain HTML + CSS.

## Deploy on Vercel

1. Import the repo at [vercel.com/new](https://vercel.com/new).
2. **Root Directory** → `landing`
3. **Framework Preset** → `Other`
4. Leave Build Command and Output Directory empty.
5. Deploy.

## Local preview

```sh
cd landing
npx serve .      # or: python -m http.server
```

## Files

- `index.html` — page markup
- `styles.css` — Geist/Vercel design system
- `assets/` — logo + the four language screenshots
